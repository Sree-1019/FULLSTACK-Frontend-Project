Live Quiz Application

The Live Quiz Application is an interactive web-based platform designed for hosting and playing quizzes in real time.
It provides an engaging way for users to create, host, and participate in quizzes — making it ideal for classrooms, events, or fun competitions.

The project demonstrates clean UI design, modular code structure, and efficient client-side logic using HTML, CSS, and JavaScript.


✨ Features

✅ For Hosts
Create and publish custom quizzes.

Choose from multiple question types (MCQs, True/False, Short Answers).

Automatically generate a PIN code for players to join.

View quiz history and manage hosted quizzes.


✅ For Players
Join a quiz using the unique PIN shared by the host.

Answer questions live with a smooth, responsive UI.

View the final score and feedback instantly after submission.


✅ General
LocalStorage-based data persistence.

Lightweight and fast — runs entirely on the browser.

Responsive layout for desktop and mobile users.


🛠️ Tech Stack
Frontend: HTML5, CSS3, JavaScript

Data Handling: Browser LocalStorage

IDE Used: Visual Studio Code
